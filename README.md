# Multi-Agent Procurement Assistant

An AI-powered procurement assistant built with **CrewAI** and **Streamlit**.

### Features

* 🔎 Search for suitable laptops
* 📋 Collect laptop specifications
* 📊 Compare products
* 🤖 Generate a final procurement recommendation

### Technologies

* Python
* CrewAI
* Google Gemini
* Tavily
* Streamlit

### Requirements

* Budget: €1,000 per laptop
* RAM: 16 GB minimum
* SSD Storage
* Intel Core i5 / AMD Ryzen 5 or above
